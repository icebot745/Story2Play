# Story2Play

## Overview

A web app that lets users create a single-screen game by describing it through images, text, voice, and drawing — no coding required.

## User Flow

### Step 1: Upload Screen Image
- User uploads an image of what the game screen should look like.
- This becomes the visual reference for all subsequent steps.

### Step 2: Identify Character Elements
- The app prompts the user to identify the character elements visible on the screen.
- Users can respond by:
  - **Typing** a description of each character/element
  - **Speaking** (voice input)
  - **Circling** elements directly on the uploaded image

### Step 3: Define Character Movements
- The app asks the user to explain how characters move and behave.
- Examples: reactions to arrow keys, auto-movement, jumping, shooting, etc.

### Step 4: Define Win Condition
- The app asks the user how the game is won.
- Examples: reach the end, collect all items, defeat all enemies, survive for X seconds, etc.

### Step 5: Special Rules / How to Play
- The app asks for any additional gameplay rules.
- Examples: how scoring works, lives/health system, power-ups, time limits, etc.

## Notes

- This is the initial scope. More steps and features will be added later.
- The app should guide the user conversationally through each step, one at a time.
